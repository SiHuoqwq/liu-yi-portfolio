# 项目图片阅读增强设计规格

> 状态：用户已于 2026-08-13 明确授权直接执行。

## 目标

在不改变 Evidence Trace 视觉方向、页面结构、字体、颜色与既有动效体系的前提下，完成三项定向增强：

1. 首页 Evidence Trace 的界面文案改为中文；
2. 首页和两条 Case Study 中的全部真实项目截图支持点击放大；
3. 两条 Case Study 的首屏均提供清晰的“返回首页”入口。

## 方案取舍

- 不使用“新标签页打开原图”：实现简单，但会打断作品集阅读。
- 不实现带缩略图、前后切换和缩放手势的完整轮播灯箱：超出当前需求，也会引入新的视觉主角。
- 采用单图沉浸预览：点击任一真实项目截图后，在当前页面打开克制的全屏遮罩；支持关闭按钮、遮罩点击、Escape 和焦点恢复。这是本轮采用方案。

## 文案

Evidence Trace 保留编号、轨迹线与原有工程语义，仅将界面词汇改为：

- `轨迹 / 0001`、`证据路径`
- `意图 / 已约束`
- `计划 / 已编译`
- `计算 / 确定性`
- `证据 / 已验证`
- `产物 / 已交付`
- `轨迹完成`

## 组件与交互

- `ProjectScreenshot` 继续负责资产可用性与尺寸；仅真实可用图片获得放大入口，占位图不可点击。
- 新增独立 `ImageLightbox`，负责对话框、滚动锁定、Escape、遮罩关闭和关闭后焦点恢复。
- 放大图使用原始 WebP，不拉伸、不生成新素材；桌面和移动端均以 `object-fit: contain` 完整显示。
- `CaseStudyHero` 在现有标题与状态之前增加路由链接“返回首页”，两条项目页共享同一实现。
- 不添加轮播、下载、图片编辑、手势缩放或新的第三方依赖。

## 视觉令牌

- 颜色、字体、圆角与焦点颜色全部复用既有令牌。
- 遮罩使用接近作品集主背景的高不透明黑色；图片边框复用 `--color-border-strong`。
- 打开/关闭仅使用短时透明度变化；Reduced Motion 下由现有全局规则即时降级。
- 本轮签名元素仍是 Evidence Trace；图片预览只提升证据阅读，不成为新的装饰性视觉。

## 可访问性与测试

- 截图触发器有明确中文 accessible name；预览使用 `role="dialog"` 和 `aria-modal="true"`。
- 打开后焦点进入关闭按钮；Escape 或关闭后焦点回到原截图；预览开启时锁定页面滚动。
- 单元测试覆盖中文 Trace、打开/关闭/焦点恢复和两个项目页的返回入口。
- Playwright 覆盖真实路由下的点击放大、Escape 关闭及首页返回。
- 最终执行 typecheck、lint、Vitest、Playwright、production build，并检查 1440x900、1024x768、390x844。
