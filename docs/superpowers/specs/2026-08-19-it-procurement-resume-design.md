# IT 采购岗位定向简历设计规格

**日期：** 2026-08-19

**候选人：** 刘燚

**目标岗位：** IT 采购（AI 工具应用方向）

## 1. 目标

以现有单页 AI 应用开发简历为内容底稿，加入房地产销售实习经历，并针对目标 IT 采购岗位重新组织信息层级。新版需要让招聘方快速理解候选人的三项匹配价值：

1. 能理解软件、API、数据库与 AI 产品，具备 IT 品类沟通所需的技术基础；
2. 有真实的客户需求沟通、回访跟进、跨部门协作与数据整理经验；
3. 能使用 DeepSeek、Codex、Claude Code 等 AI 工具辅助分析、开发、审查和验收。

新版不得把销售经历包装成采购经历，也不得补写未实际参与的供应商寻源、询价比价、合同谈判、采购下单、交付监控或供应商绩效管理。

## 2. 目标岗位依据

目标 JD 的核心工作包括 IT 品类需求收集、采购询报价、供应商寻源、合同与订单、交付和供应商管理；优先要求采购实操、IT 品类经验、沟通协调能力及 AI Agent 工具使用经验。

候选人目前不具备可证明的完整采购实操或供应商管理经历。简历策略是突出可迁移能力与 AI 技术差异化，不直接宣称满足采购年限或全流程经验。

## 3. 内容策略

采用“单页转型型”方案，标题使用：

> 求职方向｜IT采购 · AI工具应用

简历顺序为：

1. 姓名、求职方向、联系方式与 GitHub；
2. 个人概况；
3. 核心能力；
4. 实习经历；
5. 项目经历；
6. 教育背景。

个人概况应明确候选人为信息与计算科学应届本科生，具备 IT 技术理解、需求沟通、数据分析及 AI 工具应用能力；表达转向 IT 采购的动机，但不使用“资深”“熟悉采购全流程”等无法证明的措辞。

核心能力按岗位阅读逻辑分为：

- **IT 与 AI 理解：** Python、SQL/MySQL 基础、REST、数据库、DeepSeek API、RAG、Tool Calling，以及 Codex、Claude Code 等 AI 辅助工具；
- **数据与流程：** 数据整理、结构化分析、需求拆解、状态跟踪、异常处理和结果验收；
- **沟通与执行：** 客户需求梳理、回访跟进、跨部门协作、活动执行与反馈同步；
- **工程基础：** FastAPI、React、Git 和测试验收能力，作为理解 IT 产品和与技术团队沟通的证据。

不列入未使用过的 Qoder、悟空、OpenClaw，也不补写 Excel 熟练度、采购系统或 ERP 使用经验。

## 4. 实习经历文案

**桐梓县宏兴房地产开发有限公司｜销售实习生｜2024.07–2024.09**

- 协助接待并回访客户，梳理实际需求与重点关注事项，持续跟进沟通进度，并向团队同步客户反馈，支持后续方案调整。
- 参与促销活动策划与现场执行，配合销售、策划等团队协调信息及任务节点，推动活动安排落地。
- 整理汇总销售数据与客户反馈，分析常见需求和沟通问题，据此优化推广话术与后续跟进重点。

以上内容仅使用原简历与用户确认过的真实职责进行适度专业化表达，不增加无法验证的结果数字。

## 5. 项目经历处理

保留“析数”和“KnowledgeFlow AI”两个项目，但每个项目压缩为 2 条要点：

- “析数”突出数据需求理解、结构化分析、确定性计算、结果校验及完整交付；
- “KnowledgeFlow AI”突出文档和知识信息处理、检索与来源追踪、AI 问答边界及系统实现；
- 保留关键技术栈，但弱化大量测试数量与版本号，避免抢占岗位相关信息；
- 不将项目包装为采购项目、供应商系统或企业生产经验。

## 6. 视觉与版式

- 输出 A4 单页 PDF；
- 采用白底、深蓝标题、黑灰正文的克制商务风格；
- 保留证件照，但缩小其视觉权重；
- 使用清晰的两级标题、细分隔线和紧凑但可读的段落间距；
- 不使用能力进度条、星级、复杂图表、装饰性时间轴或大面积色块；
- 正文在 100% 缩放下应清晰可读，中文不得出现乱码、重叠、孤行或裁切；
- 版式优先保证招聘系统可提取文本，联系信息与章节标题使用真实文字而非图片。

## 7. 交付与验证

最终交付一份岗位定向 PDF，文件名保持清晰稳定。制作后执行：

1. 提取全文，核对姓名、联系方式、日期、公司、项目和所有要点；
2. 将 PDF 渲染为 PNG，检查单页边界、字号、行距、分栏对齐、照片和中文字体；
3. 检查没有未批准的采购经历、工具或量化成果；
4. 保留原始两份 PDF，不覆盖源文件；
5. 将新版交付到 `D:\Codex\Outputs` 下的独立目录，并同步更新作品集项目中的正式简历仅在用户另行确认后进行。

## 8. 非目标

- 不改动作品集网站；
- 不覆盖现有正式 AI 应用开发简历；
- 不制作英文版；
- 不虚构采购、供应商、合同、订单、ERP 或企业上线经历；
- 不调用图片生成工具，也不修改候选人照片。
