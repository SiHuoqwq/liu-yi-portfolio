# 面试双页速查图设计规格

## 目标

将用户提供的四张聊天截图与本次对话中已经确认的 ERP、智能排柜、自我介绍、公司业务理解和现场沟通内容，整理成两张可打印、可在手机上放大的 A4 竖版中文速查图。每个要点必须带有可直接复述的文字，不能只保留抽象关键词。

## 输出

- 第 1 页：`01-erp-smart-container-cheatsheet.svg/png`
- 第 2 页：`02-interview-qa-cheatsheet.svg/png`
- 画布：1800×2546，接近 A4 纵向比例
- 目录：`D:\Codex\Outputs\interview-prep-2026-08-18\cheat-sheets\`

## 第 1 页：ERP 与智能排柜

1. 七步记忆条：数据 → 校验 → 规则 → 求解 → 审批 → 落库 → 变更。
2. ERP 一句话定义及这家公司的端到端业务链路。
3. 七步系统处理逻辑，每步附一至两句解释。
4. 三个业务场景：正常排柜、生产延期、客户加急。
5. 无可替代商品时的“无解也是有效结果”。
6. AI、确定性求解器、人工审批三方边界。
7. 业务分配与真实三维装箱的阶段边界。
8. 30 秒可直接复述的讲解话术与核心句。

## 第 2 页：自我介绍与面试问答

1. 75-90 秒自我介绍，严格与正式简历一致。
2. 高频问题：同类经验、单人从零搭建、项目迁移关系、为何不用大模型直接排柜、规则变化、AI 工具使用、个人不足。
3. 陌生业务问题的通用回答顺序。
4. 面试时查看提纲、忘词、薪资沟通和面试后感谢话术。
5. 反问公司的八个问题，优先突出数据现状、业务边界、验收人和三个月目标。

## 视觉系统

- 浅暖灰背景 `#F4F1E9`，适合打印并减少深色耗墨。
- 深蓝正文 `#14243A`，青绿主线 `#0F7F78`，橙色风险线 `#C96E32`，绿色审批线 `#3E7B56`。
- 白色卡片、轻阴影、编号导航和左侧色带组成统一信息层级。
- 字体：Microsoft YaHei、PingFang SC、Noto Sans CJK SC、sans-serif。
- 标题 48-56px，卡片标题 27-31px，正文 21-24px；不得依赖低于 18px 的正文承载关键信息。
- 不包含 HR 头像、手机号、邮箱或聊天截图本身。

## 验收标准

1. 两张 PNG 均为 1800×2546，所有中文无乱码、裁切和重叠。
2. 两张 SVG 可独立打开和缩放打印，不包含外部图片或字体依赖。
3. 第 1 页能够支持 30 秒概括和 2 分钟业务讲解。
4. 第 2 页能够支持自我介绍、高频问答、现场补救和反问环节。
5. 不虚构同类 ERP 上线经验、量化业绩、公司工商关系或财务系统能力。
