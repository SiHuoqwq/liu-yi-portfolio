# 智能排柜决策闭环全景图设计规格

## 目标

制作一张 1920×1350 的中文横版矢量信息图，帮助刘燚在面试中用 3-5 分钟讲清“智能排柜与供应链跟单自动化”的业务流程、技术边界和异常重排机制。最终同时交付 SVG 与 PNG。

## 核心叙事

主流程从左到右依次为：业务数据 → 数据快照与校验 → 硬/软约束 → 确定性求解 → 候选方案 → 人工审批 → ERP 执行。底部用一条醒目的回流闭环承载生产延期、客户加急、船期变化和库存差异，并回到局部重排与计划版本更新。

签名视觉是“闭环回流箭头”：它不是装饰，而是直接表达系统的关键能力并非只排一次柜，而是面对持续变化进行可解释、可审批的滚动重规划。

## 信息结构

### 1. 业务数据

- SKU 包装：箱规、尺寸、重量、CBM
- 供应：库存、在产、预计完成时间、工厂
- 需求：订单、交期、客户优先级
- 海外：库存、缺货风险
- 物流：船期、截单、40HQ 参数

### 2. 数据快照与校验

- 统一主数据、单位和时间口径
- 校验缺失、重复、异常值
- 计算可用日期与 ETA 可信度
- 固化计划时点快照与规则版本

### 3. 决策模型

硬约束：可用时间不晚于截单、体积和重量上限、必发/不可拆/禁配、订单/报关/客户约束。

软目标：优先降低逾期和海外断货风险，再提高柜体利用率，最后减少拆单、改柜和计划波动。

### 4. 求解与候选

- 以箱数作为整数决策变量
- CP-SAT / MILP / 启发式组合
- 生成候选 A/B/C
- 返回可行、最优、无解等状态
- 每个候选展示利用率、风险和调整原因

### 5. 人工审批

- 原方案与候选方案差异
- KPI、风险、移入/移出商品
- 权限校验与审批意见
- 审批前保持草稿 Plan vN

### 6. ERP 执行

- 原子化库存预留
- 更新柜计划与预计交期
- 联动采购、销售、发货和单据
- 通知相关人员
- 记录审计日志

### 7. 动态重排闭环

触发事件 → 影响分析 → 冻结不受影响部分 → 等待/移柜/替代/剔除决策 → 局部重排 → 原方案/调整方案/被移出商品/下一柜安排 → 差异审批 → 新计划版本。

### 8. 三类边界说明

- AI：解析工厂反馈、抽取异常字段、解释方案、生成通知、自然语言查询。
- 确定性求解：容量、库存、交期和整数分配；无解时返回冲突原因与最小放宽建议。
- 阶段边界：MVP 先解决“哪些箱进入哪个柜”；三维摆放需要朝向、堆叠、承重、托盘、重量分布和装卸顺序等额外数据。

## 视觉系统

- 背景：深海军蓝 `#07111F`，卡片 `#0E1C2F` / `#11243B`
- 主流程：青色 `#33D6C5`
- 风险与异常：橙色 `#FFB454`
- 审批与成功：绿色 `#79E09A`
- 次要文字：`#A9B8CC`，正文：`#F5F8FC`
- 字体：Microsoft YaHei、PingFang SC、Noto Sans CJK SC、sans-serif
- 画布：1920×1350，安全边距 56px
- 所有标签使用真实业务术语，不使用公司 Logo，不虚构上线指标

## 验收标准

1. 1920×1350 PNG 中所有中文无截断、重叠或乱码。
2. 主流程、异常闭环和三类边界在一张图上完整呈现。
3. 面试者可按编号从左到右讲解，并能从异常事件回到新计划版本。
4. 明确区分 AI、确定性求解器与人工审批。
5. 明确区分业务分配 MVP 与真正三维装箱。
6. SVG 可缩放打印，PNG 适合手机查看。
